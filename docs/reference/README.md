# Художественные исходники

Здесь остаются материалы, необходимые для художественного направления и перепаковки ассетов. Они не загружаются приложением.

- [coastal-shop-approved-visual.png](coastal-shop-approved-visual.png) — закреплённый эталон игрового экрана.
- [coastal-shop-concept.png](coastal-shop-concept.png) — исходник `shop.webp`, который читает `scripts/prepare-art.py`.
- [coastal-shop-gameplay-art-prompt.txt](coastal-shop-gameplay-art-prompt.txt) — задание эталона.
- [coastal-shop-art-prompt.txt](coastal-shop-art-prompt.txt) — задание исходного интерьера.

Контрольные суммы сохранённых оригиналов — [manifest.json](manifest.json). Новые исходники и происхождение ресурсов описываются в [ASSETS.md](../art/ASSETS.md). Старые прототипы и рыночные документы удалены из текущего дерева по запросу пользователя; при необходимости они доступны в истории Git.

Текущий план игры — [CONTENT_MASTER_PLAN.md](../CONTENT_MASTER_PLAN.md), реализованные правила — [GAME_DESIGN.md](../GAME_DESIGN.md).
