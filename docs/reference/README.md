# Архив исходных материалов

Все материалы находятся внутри репозитория. Они сохранены для проверки первоначальных решений и художественного направления; приложение их не загружает и не исполняет. Старый чат, внешняя папка и прежний сервер документов для работы не нужны.

- [coastal-shop-gamedoc.html](coastal-shop-gamedoc.html) — первоначальный визуальный геймдок v0.3; содержит встроенные Base64 изображения. Для чтения без картинок: [coastal-shop-gamedoc.txt](coastal-shop-gamedoc.txt).
- [yandex-games-report.html](yandex-games-report.html) — исходный рыночный отчёт с гипотезами экономики; текст: [yandex-games-report.txt](yandex-games-report.txt).
- [coastal-shop-approved-visual.png](coastal-shop-approved-visual.png) — выбранный художественный эталон игрового экрана.
- [coastal-shop-concept.png](coastal-shop-concept.png) — концепт интерьера, использованный для локального WebP фона.
- [coastal-shop-level-generator.js](coastal-shop-level-generator.js) — исходная демонстрация правил и генератора. Реальное ядро текущего приложения — src/engine.ts и src/generator.ts.
- [coastal-shop-gameplay-art-prompt.txt](coastal-shop-gameplay-art-prompt.txt) — исходное задание для иллюстрации игрового экрана.
- [coastal-shop-art-prompt.txt](coastal-shop-art-prompt.txt) — исходное задание для концепта интерьера.

Семь оригинальных файлов сохранены без редактирования, ранее сверены с предоставленными источниками по SHA-256. Их текущие контрольные суммы записаны в manifest.json. При анализе HTML читать текст или извлекать разделы, не выводить длинные Base64 строки.

Архивные ссылки на localhost и внешние официальные сайты описывают прежние демонстрации или источники исследования. Они не являются путями к игровым ассетам и не требуются сборке. Для новой разработки использовать README, docs/HANDOFF.md и docs/GAME_DESIGN.md; для дальнейшей платформенной интеграции актуальные условия проверять по официальным источникам.
