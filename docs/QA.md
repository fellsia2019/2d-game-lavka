# Проверка среза 0.1.0

Дата: 4 октября 2026. Среда: Windows, Node.js 22.17.0, Codex In-app Browser (Chromium). Это проверка локального среза, не платформенная сертификация и не исследование удержания.

## Автоматические проверки

`npm test`: 15 тестов, все прошли.

- Первая задача решается четырьмя переносами с тремя отправками; товарные количества сохраняются.
- Неверные переносы не меняют состояние, закрытые товары недоступны; перемещение не мутирует исходное поле.
- Каскады троек, раскрытие задних рядов и открытие поставок; отмена возвращает весь снимок.
- Победа допустима последним ходом испытания; после исчерпания бюджета перенос запрещён. Основная глава без лимита.
- Резерв хранит один предмет, не отправляет тройки и сохраняет количества.
- Все десять задач главы имеют воспроизведённые решения и различные структурные ключи.
- 128 задач: по 32 seed в каждом профиле front/layers/crate/mixed. Каждая повторно сгенерирована для проверки детерминизма; найденный путь воспроизведён до победы без помощи. Это новая выборка текущего генератора, отдельная от 400 задач исходной демонстрации.
- Структурное сравнение не считает переименование товаров, перестановку мест и полок новой задачей.
- Исчерпание ограниченного поиска возвращает unknown, а не impossible.
- Проверенное перемешивание сохраняет товарные количества, скрытые ряды, поставки и доставленное; его решение воспроизводится.
- Сохранение восстанавливает закреплённую задачу, текущее поле и отмену; повреждённая попытка или недоступное storage не приводят к падению.
- Победа начисляется однократно; повторные награды ограничены; ремонт стоит три звезды один раз, смена цвета бесплатна.

`npm run build`: строгая проверка TypeScript и production build прошли. Итог: **685 449 байт**, примерно **0,65 МиБ**, все файлы `dist` без распаковочных/сетевых поправок. Перечень и размеры: `build-size.json`. Worker собирается отдельным JS-файлом. Источники, исходные PNG, reference HTML, тесты и документация в dist не входят.

## Через интерфейс браузера

Проверки проводились взаимодействиями с реальными кнопками/слотами. Решения для прохождения QA читались из сохранённого проверенного пути; это проверяет интерфейс и переходы, но не способность незнакомого игрока решить задачу.

- Последовательно пройдены все десять заказов: результат, переходы, задние ряды, поставки, финал главы.
- Мышь: выбор → свободное место, запрещённое занятое место и перетаскивание; клавиатура: Enter переносит выбранный предмет.
- Перезагрузка в середине попытки сохраняет поле; продолжение и отмена восстанавливают состояние. Перезапуск сохраняет исходную Definition, не создаёт новую задачу.
- Бесплатные подсказка, перемешивание и резерв применяются; подсказка не списывается повторно, пока показан тот же шаг. После перемешивания задача полностью пройдена.
- После первых трёх побед куплена коралловая вывеска за три звезды; перезагрузка сохранила ремонт, смена на бирюзовую прошла бесплатно.
- Все десять новых заказов суммарно дали 600 монет / 10 звёзд; после ремонта осталось семь звёзд. Повторные заказы дали по десять монет без новой звезды. Перезагрузка результата не начисляет награду ещё раз.
- Переключатели звука, музыки и уменьшения движения восстановились после перезагрузки.
- Запись настроек во второй вкладке вызвала блокирующий диалог обновления в первой. Устаревшая вкладка больше не должна перезаписывать прогресс.
- При повторе после завершённой главы исправлен и повторно проверен переход «Вернуться в лавку».
- Desktop 1280 × 720; мобильные 360 × 740 и 360 × 640; альбомный 640 × 360. На последних двух размерах поле, шесть полок, четыре цели и кнопки помещаются без горизонтальной прокрутки. Проверены загруженные изображения и размеры игровых интерактивных зон не менее 44 × 44.
- Touch обработчики проверены синтетическими PointerEvent с pointerType=touch: перенос и отмена сработали. Физическое касание на телефоне и полноценная эмуляция native touch ещё не проверены.
- Отдельно открыта production-сборка через `npm run preview` на localhost:4173: первый заказ создан worker, все изображения загрузились, перенос изменил поле. После произвольного хода и отмены новый путь подсказки найден поиском в worker; подсвеченный ход отправил тройку. Ошибок/warnings в консоли проверенной вкладки нет.

Все семь копий reference файлов дополнительно сверены по SHA-256 с исходными материалами: совпадают.

Браузерные проверки выполнялись в отдельных origin для разработки и production. Тестовый прогресс 127.0.0.1:5173 не переносился в игровой localhost:5173 или :4173.

## Что ещё не подтверждено

Нужны физические мобильные устройства, Safari/Firefox/Edge, встроенные браузеры платформы, слабые устройства, субъективное качество звука и тестирование SDK/рекламы/платежей после их реализации. Нет облачного сохранения, аналитики, системы большого количества ремонтных узлов, промышленной защиты от повторов на длинной серии и локализаций. Локальная экономика не защищена от ручного редактирования сохранения. Нет результатов реальных игроков или доказательства доходности и 50–100 часов удержания. Дополнительные проверки описаны в `RELEASE.md`.

## Проверка самостоятельности репозитория

После обновления документации 4 октября 2026 года создан отдельный чистый clone коммита первого среза из main. В нём отсутствовали node_modules и dist; никакие ассеты из внешней папки не копировались.

- `npm ci` установил зависимости из package-lock: аудит 22 пакетов, без обнаруженных уязвимостей на момент проверки.
- `npm test`: все 15 тестов прошли, включая 128 задач текущего генератора.
- `npm run build`: TypeScript и Vite прошли; dist — 685 449 байт, как в исходном checkout.
- Семь архивных файлов совпали с repo manifest.json по SHA-256, включая HTML и оригинальные изображения. Git сохраняет их байты без преобразования строк.
- Проверены 22 локальные Markdown ссылки; отсутствующих целей нет. Все восемь runtime WebP присутствуют.
- После установки и сборки рабочее дерево чистого клона осталось чистым.

В main включены исходники, lockfile, WebP, исходные PNG, reference материалы, актуальный дизайн, точка продолжения и скриншоты. Прежний чат, внешние HTML, папки Codex, image_gen и Python не нужны для запуска/тестов/сборки. Зависимости npm остаются инструментами разработки; повторная генерация или Python требуется только при отдельной художественной работе, не при клонировании игры.
