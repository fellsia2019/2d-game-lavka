# Проверка версии 0.2.0

Последняя автоматическая проверка: **5 октября 2026 года**, macOS, Node.js 22.14.0. Интерфейс проверялся 4–5 октября в Codex In-app Browser на локальной production-сборке.

В проверенных сценариях блокирующих ошибок не обнаружено. Завершён цикл «заказы → награды → три ремонта → финал». Контент добавляется через [CONTENT.md](CONTENT.md) с проверкой каждой задачи.

## Автоматические проверки

`npm test`: **28 тестов прошли**. Покрыты переносы, каскады, задние ряды, замки, бюджет, резерв, тупик и отмена; экономика, повторные награды и ремонт; сохранение каждого хода главы, миграция schema 1 → 2, старые id, кеш подсказок, повреждённая попытка и будущая schema без записи. Worker проверен при успехе, ошибке, тайм-ауте, некорректном ответе и ошибке postMessage.

В тестах воспроизведены все десять заказов, 128 детерминированных seed четырёх профилей и все девять рецептов.

`npm run build`: TypeScript, проверка каталога, Vite и ограничение размера проходят. Десять решений воспроизведены, структуры различны, стоимость ремонта — 10 из 10 доступных звёзд. Весь `dist` занимает **1 045 483 байта**, меньше бюджета 80 000 000 байт. Отчёты: [контент](content-report.json), [размер и файлы](build-size.json).

Дополнительная выборка генератора от 4 октября: `npm run content:audit`, seed audit-0…audit-99 каждого профиля без истории исключений. Все 400 решений воспроизведены, unknown=0 в этой выборке. [Отчёт](generator-report.json).

## Игровой цикл

Основной прогон 0.2.0 от 4 октября использовал отдельный origin 127.0.0.1:4174. Через реальные кнопки пройдены десять заказов, куплены три ремонта, восстановлены попытка и финал после перезагрузки. Проверены:

- блокировка будущих заказов, смена незавершённой попытки и возврат к ней;
- подсказка без повторной оплаты после навигации, сохранения и отмены; перемешивание, перезапуск и последующая победа;
- резерв, перенос туда/обратно, отмена, сохранение рядов и замков;
- осмотр готовой лавки, три объекта, бесплатный цвет и повтор с +10 монет/+0 звёзд;
- настройки, клавиатурный ввод, удержание фокуса в диалогах, перетаскивание, экспорт локального журнала и конфликт двух вкладок;
- загрузка реального сохранения 0.1.0 без сброса: старая раскладка десятого заказа, товары, ряды, замок, оформление и баланс сохранились. До победы эта старая задача в браузере не проходилась; миграция и награды покрыты тестами.

Мастерская проверена 4 октября: генерация, исключение предыдущей структуры, пошаговое решение до победы, экспорт, импорт того же файла, отклонение неверного JSON и пустого seed. [Снимок](screenshots/content-workshop.png). После последних правок игрового UI мастерская заново не проходилась.

## Обучение и компоновка

После сообщения пользователя о перекрытии первых полок выполнен повторный прогон 4–5 октября на отдельных origin localhost:4175 и 127.0.0.1:4176. Пользовательский профиль не сбрасывался.

- Первый заказ пройден через Enter, клики и реальное перетаскивание. После первого переноса reload сохранил поле и следующий учебный шаг.
- Во время обучения активны только текущая цель и «Пропустить». Акцент переходит с товара на место назначения; Tab переключает цель и пропуск. Пропуск сохраняется после reload без награды.
- На седьмом заказе четыре учебных переноса раскрыли ряд и сняли затемнение; на девятом восемь переносов открыли замок. Оба заказа затем завершены.
- Обычная подсказка выделяет одну цель. Закрытие, повтор и reload того же шага не расходуют второй подарок; фокус возвращается к товару.
- На четвёртом заказе при нуле подарков и 80 монетах учебный показ сработал бесплатно, баланс остался 80. Повтор после reload также бесплатен.
- Снова завершены все десять заказов и три ремонта. Повтор десятого заказа с платным резервом завершён без новой звезды; финал восстановился после reload.
- На восьмом заказе тупик воспроизведён переносами [1,0]→[2,0], [1,1]→[3,0] (индексы с нуля). Две отмены вернули исходное поле; заказ завершён.
- На 640 × 360 три объекта готовой лавки видны, кнопки имеют высоту 44 px. Окно купленных цветов открывается, «Готово» бесплатно возвращает к финалу.
- В журнале последнего проверенного прогона ошибок и предупреждений нет.

## Оставшиеся проверки

- Физические Android/iOS: касания, перетаскивание, поворот, панели браузера, скрытие и возврат. Изменение viewport desktop-браузера не подтверждает поведение телефона.
- Safari, Firefox, Edge, встроенные браузеры, слабые устройства и длительные сессии.
- Новички без объяснений: понимание переноса, рядов, замков и отмены. Прохождение по известному решению этого не проверяет.
- Автоматические проверки UI для обучения, перекрытий, сохранения и переходов до финала; сейчас UI проверяется вручную.
- Компоновка без прокрутки основного игрового поля для платформенного выпуска; в локальной версии короткие окна прокручиваются. Требования, SDK, реклама, платежи, облако и опубликованная сборка — по [RELEASE.md](RELEASE.md).

Основная глава не содержит испытаний с бюджетом ходов; они проверены на уровне ядра. Нет измерений удержания, доходности или подтверждённой кривой сложности. Заявление «100% без багов на любых устройствах» результатами этого QA не подтверждается.
