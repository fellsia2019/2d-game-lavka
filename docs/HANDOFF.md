## Полный продукт

Первый публичный выпуск — **1800 заказов, 480 работ, шесть глав, 24 этапа с возвращениями и финал**. На локацию — 300/80; этапы — 60/70/80/90 заказов и двадцать работ каждый. Каталог — [CONTENT_CATALOG.md](CONTENT_CATALOG.md), данные — docs/content/full-product-plan.json. Пакеты разработки являются внутренними итерациями.

У пяти новых площадок подготовительные четыре работы стоят 10 ★ внутри бюджета этапа. Заказы доступны до оплаты стройки; все 1800 звёзд финансируют 480 обязательных работ. Карта сохраняет пляж, набережную и путь покупателей. Изменяемые заросли, здания, мебель и товары — отдельные слои; все ресурсы в репозитории.

## Проверки и производство

npm test — правила/сохранения; npm run build — TypeScript, план, готовые решения и весь dist <80 000 000 байт. UI — npm run test:ui на изолированном origin 127.0.0.1:4190. Итоги фактических прогонов — [QA.md](QA.md).

npm run content:produce-shop готовит второй блок офлайн и сохраняет закреплённые записи. npm run content:plan проверяет план. После его изменений node scripts/check-content-plan.mjs --write обновляет каталог, отчёт и runtime-план. Статусы implemented-definition/implemented ставить только после реального производства; build сопоставляет их доступному каталогу. Плановый checker подтверждает арифметику и зависимости, а не будущие решения или UI.
