# Продолжение разработки

Текущая версия — **0.2.0**, состояние на 5 октября 2026 года. Завершён локальный цикл «10 заказов → награды → 3 ремонта → финал». Работают осмотр лавки, бесплатная смена оформления, повторы и мастерская контента. Обучение использует одну яркую цель; длинные игровые тексты убраны. Перекрытие полок исправлено на проверенных мобильных и низких desktop-размерах.

## Воспроизведение

`npm ci` → `npm test` → `npm run build` → `npm run preview`.

Игра — http://localhost:4173, мастерская — http://localhost:4173/author.html. Для разработки: `npm run dev`, порт 5173. Все ресурсы находятся в репозитории.

Правила — [GAME_DESIGN.md](GAME_DESIGN.md), процесс наполнения — [CONTENT.md](CONTENT.md), результаты проверки — [QA.md](QA.md). Build пересчитывает [content-report.json](content-report.json) и [build-size.json](build-size.json); дополнительная проверка генератора — `npm run content:audit`.

## Сохраняемые договорённости

- Работать в `main` по [AGENTS.md](../AGENTS.md).
- Глава хранит проверенные Definition в `src/levels/chapter.json`. Каталог и стабильные id — в `src/content.ts`; CONTENT_VERSION — coastal-chapter-2, генератор — coastal-slice-2. Выпущенную задачу не подменять новой генерацией.
- Продолжение, помощь и перезапуск сохраняют исходную Definition, seed и версию. Исчерпание поиска означает неопределённость; найденный путь проверяется воспроизведением.
- LocalStorage: ключ `coastal-shop:progress:v1`, schema 2. Миграция schema 1 сохраняет старую задачу и прогресс; фиксированный LEGACY_IDS предотвращает повторную звезду. Будущая schema не перезаписывается.
- QA проводить на отдельном origin или профиле. Пользовательские сохранения не сбрасывать; Git их не переносит.
- Runtime WebP — в `public/assets`, исходные PNG и происхождение — в `docs/art`. Архив `docs/reference` сохранять без изменения.
- Временные результаты — в игнорируемом `artifacts`; полезные актуальные скриншоты — в `docs/screenshots`. Бюджет всего `dist` — меньше 80 000 000 байт.

## Следующие задачи

Перед массовым наполнением проверить реальные Android/iOS: касания, перетаскивание, поворот, изменение высоты при появлении панели браузера и возврат в игру. Проверка desktop-браузера на ширине 360 px не заменяет эти испытания.

Наблюдать новичков без устных объяснений: первый перенос, понимание рядов и замков, отмена, ошибки и выходы. На основе наблюдений корректировать обучение и порядок задач; длина найденного пути не измеряет интерес или сложность.

Добавить автоматические проверки интерфейса: обучение, перекрытия на контрольных размерах, продолжение и переходы до финала. Сейчас правила и сохранения покрыты тестами, а интерфейс проверялся вручную. Границы выполненных проверок перечислены в QA.

Новый контент можно готовить через мастерскую и проверяемый каталог. Перед выпуском пройти [RELEASE.md](RELEASE.md): другие браузеры, платформа, SDK, облако и монетизация. Текущая прокрутка игрового поля в коротких окнах требует отдельной адаптации к требованию Яндекс Игр о доступности основных элементов без прокрутки.
