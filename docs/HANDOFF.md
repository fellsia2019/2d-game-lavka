# Точка продолжения

Первый этап **завершён**: играбельный срез 0.1.0. Во время проверки случился разрыв соединения и остановился локальный сервер; исходники, ассеты, документация и dist сохранились. Незавершённой операции генерации или недописанного уровня на этой границе нет.

Документ рассчитан на новую сессию разработки без доступа к предыдущему чату. Главные команды, игровой дизайн и материалы находятся в этом репозитории.

## Текущее состояние

- TypeScript + Vite, DOM/CSS 2.5D, без библиотек в runtime.
- Десять последовательных заказов: три ручных, семь отобранных seed, четыре семейства генерации.
- Лавка, игровое поле, результат, книжка заказов, настройки, справка и диалоги.
- Один ремонт — вывеска над окном. Покупка за три звезды, три цвета, дальнейшая смена бесплатна.
- Правила троек, раскрытие рядов, открытие поставок, бесплатные отмена и перезапуск; игровая помощь за подарочные единицы или игровые монеты.
- Локальное сохранение закреплённой задачи и попытки. Восстановление отмены, проверка сохранения, однократная выдача наград, защита устаревшей вкладки от перезаписи.
- Отдельные товары/полка в WebP, интерьер из предоставленного концепта, UI и изменяемая вывеска отдельными элементами, Web Audio эффекты и мелодия.
- Генерация, поиск подсказки и проверка перемешивания в ограниченном worker.
- SDK, реальные рекламные показы, платежи, облачная синхронизация и аналитика **ещё не реализованы**.

## Как воспроизвести

Из корня чистого checkout: `npm ci`, `npm test`, `npm run build`. Затем `npm run preview` и http://localhost:4173. Для разработки использовать `npm run dev` и http://localhost:5173. Не открывать index.html двойным кликом: module worker требует HTTP.

Все runtime ассеты уже в public/assets. Повторная генерация image_gen и перепаковка Python не нужны. Исходные PNG для дальнейшей художественной работы находятся в docs/art, художественный ориентир и остальные семь источников — в docs/reference. Старые localhost-адреса в архивных материалах описывают прежние демонстрации; их серверы запускать не требуется.

Прогресс хранится в localStorage браузера под ключом `coastal-shop:progress:v1`. Git не переносит текущую попытку игрока на другой компьютер. Разные host/port имеют отдельные сохранения. Для нового тестового профиля использовать отдельный origin или чистый профиль браузера; пользовательское сохранение не сбрасывать без запроса.

## Проверено на первой границе

15 автоматических тестов прошли. 128 задач текущего генератора в четырёх профилях воспроизведены до победы. Все десять заказов главы пройдены через браузер; проверены ремонт, продолжение после перезагрузки, помощь, повторные награды и настройки. Проверены 1280 × 720, 360 × 740, 360 × 640 и 640 × 360. Синтетический touch проверен; физических телефонов и всех браузеров в этой проверке не было.

Production-сборка около 0,65 МиБ; фактические размеры пересчитывает каждый build и записывает docs/build-size.json. Более подробные свидетельства и ограничения: [QA.md](QA.md), скриншоты — в [screenshots](screenshots/).

Дополнительно проверен самостоятельный чистый clone main: `npm ci`, 15 тестов и сборка прошли без старого чата или внешних материалов. Семь архивных checksum совпали, восемь WebP и 22 локальные ссылки документации проверены. Документация актуализирована; новый функциональный этап после первого среза не начат.

## Следующие этапы

Начать с тестирования среза на игроках и уточнения обучения. Затем расширить контент и развитие лавки: примерно 15–25 ручных обучающих/особых задач, новые семьи генерируемых задач, подавление структурных повторов, дополнительный ремонт с отдельными слоями. После проверки основного цикла подключить платформенный адаптер и SDK; рекламную и платёжную интеграцию делать последующими этапами. Порядок и проверенные официальные источники — в [RELEASE.md](RELEASE.md).

Генератор — стартовая реализация generate-and-test. Для длинной серии ещё нет истории структур и доказанной кривой сложности. Десять заданий не доказывают 50–100 часов удержания. Рыночный отчёт, цены и оценки выручки — гипотезы для проверки на реальных данных.

Git remote: https://github.com/fellsia2019/2d-game-lavka. Работа, коммиты и push — в main по AGENTS.md. В репозиторий входят исходники, lockfile, ресурсы, исходные PNG, reference материалы, документы и скриншоты. node_modules, dist, временные логи и локальные сохранения в Git не включаются.
