# Игровые товары пекарни

Два самостоятельных товара созданы встроенным ImageGen: `baguette-v1.png` и `croissant-v1.png`. Рядом находятся точные задания `baguette.prompt.txt` / `croissant.prompt.txt`. Исходники RGBA 1254×1254; runtime — `public/assets/baguette.webp` и `public/assets/croissant.webp`, RGBA 320×320, суммарно 69 826 байт.

`bread.webp` и `pear.webp` лично просмотрены как ориентиры цвета, объёма, прозрачности и короткой контактной тени. Они не изменялись и не передавались в генерацию; каждый новый товар создан самостоятельным built-in вызовом. Новые PNG сохраняют настоящий alpha, один целый предмет и прозрачные поля. Края обоих багетных концов и рожков круассана находятся внутри изображения.

`export.py` только уменьшает весь исходный кадр до 320×320 и сохраняет WebP quality96 с alpha; маски, ретушь и рисование не применяются. `manifest.json` содержит пути, размеры, SHA-256 и происхождение. `scale-review.png` — диагностическая компоновка на кремовом фоне, не runtime-ассет. Лично просмотрены исходные генерации и сравнение с существующими товарами на 80, 48 и 32 px: багет отличается длинным диагональным силуэтом, круассан — открытым полумесяцем, круглый хлеб остаётся отдельной формой.

Проверка в настоящем игровом поле на desktop и 360 px ещё предстоит после интеграции root. Каталог, коды GOOD, UI и правила заказов этим заданием не изменялись.
