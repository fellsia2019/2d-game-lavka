# Архив прежних runtime-ресурсов

11 октября2026. Эти15 WebP относятся к отвергнутой диораме и прежним отдельным полкам. Текущие полные комнаты их не используют. Файлы перенесены из `public/assets` побайтно, без перекодирования; PNG-оригиналы и исторические документы сохранены. Путь и SHA-256 каждого файла — [manifest.json](manifest.json).

Существующий `hall-corner-empty.webp` остаётся в public: это фон отдельного магазина помощи. Архивные экспортёры `prepare-registered-hall.py` и `prepare-corner-furniture.py` теперь сохраняют результаты сюда и не возвращают отвергнутые ассеты в dist.
