# Карта террасы

10 октября 2026. Семь полноразмерных RGB PNG 1536×1024, производные WebP в той же системе координат. Новые изображения сделаны встроенным ImageGen; точные запросы в `prompts/`. `before.png` — точная копия `../bakery-map/final.png`, исходник не менялся. `final-draft.png` и `foundation-draft.png` — отвергнутые промежуточные результаты, не экспортируются.

Карта согласована с `../TERRACE_MODEL.md` и локальным `../terrace-rooms/master-v2.png`: четыре угловые стойки, южные центральные ступени, два столика по сторонам пути, три стула, западная скамья, северный сервисный ряд, кремово-бирюзовая ткань. Автор локальной сцены лично подтвердил соответствие. Новое каменное основание несколько глубже старой деревянной руины (примерно 20–25 px), остаётся внутри прежнего участка; точное совпадение старой и новой постройки не заявляется.

Зафиксированные ориентиры нового каркаса: передняя левая стойка около (897,520), передняя правая (1305,552), задние (953,461)/(1331,484); передние основания (896,589)/(1303,619), верхние задние блоки (956,515)/(1332,546), центральные ступени около (1080,620). Постройка занимает приблизительно x877–1348, y407–647. Внешний очищаемый участок шире строения и следует существующему садовому бордюру. Точные SVG контуры в `src/coastal-map-scene.ts`.

Регистрируется новый низкий цоколь по `frame.png`. Первый фундамент был слишком широк слева; заменён зарегистрированной версией из каркаса. Карта обобщает крупные строительные вехи: 0–1 руина, 2–6 очищенный участок (6 разметка), 7 основание с несущим настилом, 8 каркас, 9 ткань, 10–25 пустая готовая оболочка, 26 меблированная терраса. Детальные изменения 26 работ видны в основной сцене. Из `roof.png` используется только навес: генератор дорисовал лишнюю дверь позади пустой террасы, и она исключена предметным контуром. Окружение берётся из текущей карты; соседние стройки не заменяются полным донором. Два передних фонаря сохраняются целыми отдельным передним перекрывающим слоем.

Экспорт: `scripts/prepare-terrace-map-art.py`, RGB WebP quality 76 / method 6, без рисования, вырезания или ретуши PNG. Семь WebP: **1 629 482 байта**; с тремя товарами **1 754 280 байт**. `manifest.json` содержит точные размеры каждого файла.

Предварительно лично просмотрены все семь источников, восемь offline SVG состояний 0/2/6/7/8/9/10/26 и крупные фрагменты основания/навеса. Это не заменяет браузерную приёмку; её фактические границы записываются в `../TERRACE_REVIEW.md`.
