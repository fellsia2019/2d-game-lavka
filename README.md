# Лавка у моря

Онлайн-браузерная 2D-игра для **Яндекс Игр**: сортировка товаров по тройкам, восстановление заброшенного прибрежного участка и развитие большого торгового двора. Цель продукта — долгосрочная игра с устойчивой аудиторией и коммерческой монетизацией. Референсы развития — Homescapes и Gardenscapes.

## Продолжение без контекста чата

Начать с [HANDOFF.md](docs/HANDOFF.md), затем прочитать [единое принятое направление и полный план](docs/CONTENT_MASTER_PLAN.md) и [реализованные правила](docs/GAME_DESIGN.md). Работать в `main` по [AGENTS.md](AGENTS.md). Все необходимые документы, исходники и ресурсы находятся в репозитории.

**Первый публичный выпуск:** 6000 заказов, шесть локаций по 1000, шесть глобальных Stage, 36 локальных этапов и 744 постоянные работы. Локальные этапы: 80 + 120 + 160 + 200 + 220 + 220. Новую территорию сначала очистить от мусора и старых конструкций, убрать растительность и пни, подготовить площадку, построить фундамент, стены, крышу, выполнить отделку и установить базовое оборудование. Только затем доступны её внутренние заказы. Ремкомплекты зарабатываются заданиями со строительными материалами. Звёзды продуктовых заказов оплачивают обустройство.

Внутри глобального Stage игрок выбирает доступный проект: продолжить склад, вернуться в лавку или строить следующую локацию. Для следующего Stage завершить обязательные результаты всех введённых предприятий. Порядок каталога не является обязательной линейной выдачей заказов.

С первого публичного выпуска нужны ежедневные контракты, недельные проекты, коллекции, сезоны с бесплатной/платной дорожками, добровольная реклама, покупки, облако и аналитика. Кампания не требует покупки пропуска. Нативное мобильное приложение не разрабатывается; поддерживаются desktop и браузеры телефонов. Доход и удержание пока не измерены.

**Фактически в 0.6.0:** весь внутренний **Stage 1–2, первая пекарня и терраса — 760 закреплённых заказов, 178 работ и 29 товаров**. Лавка I, расчистка/постройка склада I, независимый выбор лавки II/склада II/фруктового павильона и его пристройки. Каждый проект сохраняет свою незавершённую попытку. После шести прежних проектов открывается пекарня: строительство, вход и торговый зал, затем рабочая кухня. Готовы восемь проектов; остальные 760 заказов / 100 работ Stage 3 и дальнейшие стадии полного продукта ещё готовятся.

Лавка I содержит **14 крупных работ за 19 ремкомплектов и 61 ★** и два полноценных интерьерных кадра, выбранных пользователем: вход/витрины/касса и подготовка заказов. PixiJS отрисовывает 2D-слои в исходных координатах 1536×1024; два угла выбираются карточками через глобус в верхней панели. Отдельная кнопка возвращает на карту двора; нажатие на доступное здание открывает выбор «Помещения и зоны», на закрытое — показывает требования. Выбор помещения переключает на его реальный этап; отмена оставляет карту и сохранение прежними. Высота плана постоянна при смене здания. Вместо переключателей «Этап 1/2» игрок выбирает помещения по иллюстрированным карточкам; рекомендуемая комната подсвечена. После завершения обустройства основная кнопка сразу открывает следующую работу, а карта остаётся доступна для осмотра. Перекраска доступна у купленного прилавка. Лавка II (20 работ) теперь тоже использует два цельных вида — бакалею и кассу с входом; пол/стены меняются на всю комнату, мебель стоит вдоль стен. Оба этапа склада (46 работ) также переведены на полноразмерные согласованные кадры; все 46 работ фруктового павильона и пристройки используют четыре новых зарегистрированных кадра: строительство павильона, открытая торговля, строительство пристройки и её внутренний зал. Карта имеет отдельные согласованные состояния стройки и разные заброшенные силуэты будущих зданий. [Фруктовые помещения](docs/art/FRUIT_ROOMS.md), [карта](docs/art/COASTAL_MAP.md). Контракт лавки II — [SHOP_EXPANSION.md](docs/art/SHOP_EXPANSION.md). Контракт склада — [WAREHOUSE_ROOMS.md](docs/art/WAREHOUSE_ROOMS.md). Текущий художественный и технический контракт — [ROOM_CORNERS.md](docs/art/ROOM_CORNERS.md).

**Награды разделены:** строительные задания с краской, досками, кирпичами и крепежом дают ремкомплекты только на ремонт; продуктовые заказы дают звёзды для обустройства. В готовом блоке — 243 ремкомплекта и 517 звёзд. Цены и кнопки показывают нужную валюту; повторы дают только монеты. [Контракт и перенос сохранений](docs/REPAIR_ORDERS.md).

Монеты теперь покупают постоянное оформление лавки с бесплатной примеркой: шесть вариантов столешницы, пола и свечения ламп. Базовый ремонт и прежняя перекраска остаются бесплатными. Покупка основной работы сначала показывает нужную сцену, затем изменение со световым эффектом; управление возвращается автоматически, без надписи о завершении и кнопки «Дальше». [Оформление и направление монетизации](docs/SCENE_SHOP.md), [ремонт и показ покупки](docs/art/ROOM_POLISH.md).

Для проверки сцены: **Дебаг на сцене → здание/этап → Показать улучшение → Применить и открыть сцену**. Предыдущие работы сразу готовы, выбранная проходит с тем же визуальным эффектом, что обычная покупка. Можно открыть любой из восьми проектов, использовать пресеты и добавить валюты. В заказе доступно прежнее штатное автопрохождение; вход через настройки тоже сохранён. [Контракт дебага](docs/SCENE_DEBUG.md).

## Первая пекарня

Пекарня добавлена в игру: 80 новых закреплённых заказов, 26 покупок и три самостоятельных полноразмерных вида. GPT-6 Astra подготовила зарегистрированные состояния стройки, рабочей кухни, торговли и участка на карте. Фасад и торговый зал сохраняют взаимное положение проёмов; размещение задней кухни задаёт [модель здания](docs/art/BAKERY_BUILDING_MODEL.md): главный вход, окно выдачи, боковое окно, служебный выход и печной дымник сохраняют взаимное расположение. Обустройство начинается с входного торгового зала, где дверь и большое окно соответствуют фасаду; затем продолжается в рабочей кухне. Стройка стоит32 ремкомплекта, оборудование —48 звёзд. Заказы39–80 с багетами и круассанами открываются после прилавка и лотков торгового зала на новой позиции14; выпечка поступает поставками, собственная печь обустраивается позднее. [Реализация](docs/BAKERY_IMPLEMENTATION.md), [художественное направление](docs/art/BAKERY_DIRECTION.md). Пользователь разрешил прямую реализацию дальнейших сцен без отдельного утверждения концептов; обязательны согласованная архитектура и проверка промежуточных состояний. Терраса уже добавлена; следующая локация — ресторан на втором этаже.

## Терраса у моря

После завершения первой пекарни доступна терраса: 80 новых заказов, 26 работ и один цельный вид открытой площадки. Четыре угловые стойки, полосатый навес, центральные ступени и свободный проход сохраняются на карте и в локальной сцене. Расчистка и стройка стоят 32 ремкомплекта, обустройство — 48 звёзд; внутренние заказы открываются после первых столов и стульев, на работе 14 и после 38 заказов. Пирог, булочка и лимонад имеют самостоятельные игровые спрайты. Для проверки: Дебаг → Терраса → нужная работа → Показать улучшение. [Реализация](docs/TERRACE_IMPLEMENTATION.md), [единая модель](docs/art/TERRACE_MODEL.md).

Это текущий порядок предпросмотра; полный план Stage 3–4 остаётся незавершённым. Каталожные номера 2241–2320 отделены от индексов загрузки 681–760.

## Запуск и проверка

Node.js 22.12+.

```sh
npm ci
npm run dev
```

Игра: http://localhost:5180/. Мастерская: `/author.html`. Предпросмотр сцены: `/campaign.html`. Работать через HTTP; worker не поддерживает открытие HTML как локального файла.

```sh
npm run content:plan
npm test
npm run build
npx playwright install chromium
npm run test:ui
```

Production preview: `npm run preview` → http://localhost:4173/. UI-тесты используют отдельный origin `127.0.0.1:4190`. Сохранения разных host/port и браузеров пока раздельные; облака нет.

`node scripts/check-content-plan.mjs --write` пересобирает каталог, отчёт и лёгкие runtime-цели из производственного JSON. `npm run content:produce-stage-block` проверяет и повторно сохраняет закреплённые 600 Definition; прежние seed, раскладки, версии и решения сохраняются, добавленные 80 заказов пекарни не обрезаются. `npm run content:produce-bakery` и `npm run content:produce-terrace` проверяют закреплённые пакеты и отказываются молча пересоздать изменённые исходники; ранее добавленные проекты сохраняются. Загрузка в игре идёт по проектам с кешем двух каталогов.

Весь dist должен оставаться **строго меньше 80 000 000 байт**, целевой полный пакет 64 МБ. Результаты текущих сборок и границы выполненных проверок фиксируются в [QA.md](docs/QA.md). Исходные PNG, документация и большой производственный план вне dist. Все ресурсы — внутри репозитория.
